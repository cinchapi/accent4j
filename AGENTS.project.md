# Project instructions

Instructions specific to this repo. The shared instructions in `AGENTS.md` apply
first. Rules here add to them and win on conflict.

Keep this file to what an agent cannot learn from the shared guides or from the
code: how to build and test here, facts that differ by repo, where the project's
own docs live, and any shared rule this repo overrides.

## Build and quality gates

The commands to build, compile, format, lint, and type check, how to run one
test class or file, and which of them must pass before delivery. The full test
suite runs in CI, not on a developer's machine; name a fast test tier here only
when it is a delivery gate.

## Repo layout

The modules or packages and what each one holds.

## Facts that differ by repo

The language and runtime version, the package manager, the framework and the
test runner, the formatter's width, the integration branch, the test base class,
the label set, and anything else the shared guides say to resolve per repo.

## Where to look

The project docs to read before working in a subsystem, and when to read each
one.

## Overrides

Shared rules this repo relaxes or tightens, and why.
